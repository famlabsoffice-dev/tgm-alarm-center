# TGM ALARM CENTER — APK-Installation

## Deutsch

1. Lade die APK-Datei auf dein Android-Gerät herunter.
2. Öffne die Datei über die Download-Benachrichtigung oder im Ordner **Downloads**.
3. Falls Android fragt, erlaube deinem Browser oder Dateimanager einmalig die Installation unbekannter Apps.
4. Tippe auf **Installieren** und warte, bis die Installation abgeschlossen ist.
5. Öffne **TGM ALARM CENTER**.
6. Erlaube Benachrichtigungen und die erforderlichen Geräteberechtigungen, damit Alarme und Vorwarnungen zuverlässig funktionieren.
7. Teste anschließend die App gemäß der bereitgestellten Testmatrix.

Falls Android meldet, dass bereits eine Version installiert ist, bestätige das Update. Bei einer blockierten Installation prüfe, ob die APK vollständig heruntergeladen wurde, und lade sie bei Bedarf erneut herunter.

## English

1. Download the APK file to your Android device.
2. Open the file from the download notification or from the **Downloads** folder.
3. If Android asks, allow your browser or file manager to install unknown apps. This permission only needs to be granted once.
4. Tap **Install** and wait until the installation is complete.
5. Open **TGM ALARM CENTER**.
6. Allow notifications and the required device permissions so alarms and warnings work reliably.
7. Test the app using the provided test matrix.

If Android reports that a version is already installed, confirm the update. If installation is blocked, check that the APK finished downloading and download it again if necessary.

## Sicherheitshinweis / Security note

Install the APK only if it was downloaded from the official internal team link or received from the designated project owner. / Installiere die APK nur, wenn sie über den offiziellen internen Team-Link heruntergeladen oder von der dafür verantwortlichen Projektperson weitergegeben wurde.
